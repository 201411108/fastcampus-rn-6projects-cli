# Part 5. 3가지 앱으로 완성하는 대규모 리액트 네이티브 CLI 프로젝트

이 저장소는 패스트캠퍼스 강의 [6개 프로젝트로 끝내는 React Native : 고퀄리티 앱 개발부터 수익까지 한 번에 w.커서AI](https://fastcampus.co.kr/dev_online_rn6project)의 Part 5를 기준으로 구성된 React Native CLI 프로젝트 모음입니다.

강의 소개 페이지 기준으로 이 과정은 `Expo부터 New Architecture, CLI의 복잡한 네이티브 기능까지`를 폭넓게 다룹니다.  
Part 5는 그중에서도 React Native CLI 기반 실전 프로젝트를 가장 밀도 있게 경험하는 구간입니다.

## React Native CLI를 본격적으로 다루는 파트

- Part 4에서 `리액트 네이티브 CLI에 대하여`를 다룬 뒤, Part 5에서 실제 프로젝트로 확장합니다.
- 단일 예제가 아니라 성격이 다른 3개의 앱을 직접 구성하며 CLI 개발 흐름을 입체적으로 익힙니다.
- 화면 구현보다 `카메라`, `센서`, `저장소`, `AI`, `광고`, `서비스 구조`처럼 실전 요구사항을 연결하는 데 초점이 있습니다.
- Expo 중심 학습에서 한 단계 더 나아가, CLI가 필요한 이유를 프로젝트 단위로 체감하게 해주는 파트입니다.

## Part 5에서 배우는 핵심 역량

- React Native CLI 프로젝트를 직접 구성하고 관리하는 방법
- Android와 iOS를 함께 고려하며 네이티브 기능을 연결하는 흐름
- 카메라, 센서, 저장소, 광고, AI 같은 실무 기능을 앱 안에 자연스럽게 통합하는 방식
- 화면 단위가 아니라 프로젝트 단위로 상태, 서비스, 기능을 설계하는 감각
- 단일 예제를 넘어 여러 앱을 병렬로 구현하며 서비스 확장 관점으로 사고하는 방법

## 3가지 프로젝트로 배우는 실전 CLI 개발

Part 5는 아래 3개의 프로젝트로 구성됩니다.

1. AI 식단 렌즈
2. 터보 만보기
3. 마이 헬스 플랫폼

현재 저장소에는 아래 프로젝트가 포함되어 있습니다.

```text
.
├── RnAiCamera/
└── RnTurboPedometer/
```

프로젝트 매핑은 다음과 같습니다.

- `AI 식단 렌즈` → `RnAiCamera`
- `터보 만보기` → `RnTurboPedometer`
- `마이 헬스 플랫폼` → Part 5의 세 번째 프로젝트

### AI 식단 렌즈

- 카메라와 AI를 결합해 이미지 기반 입력을 처리하는 프로젝트입니다.
- `촬영 → 분석 → 저장 → 재사용`으로 이어지는 서비스 흐름을 다룹니다.
- 외부 AI 서비스 연동, 데이터 저장, 사용자 기록 관리 같은 실전 패턴을 익히게 됩니다.
- 기능 데모가 아니라 실제 사용자 경험을 가진 AI 앱 구조를 학습하는 데 초점이 있습니다.

### 터보 만보기

- 센서 기반 기능을 React Native 앱에 연결하는 프로젝트입니다.
- 걸음 수 같은 디바이스 데이터를 앱 상태와 화면 구조에 통합하는 방식을 다룹니다.
- 네이티브 기능과 React Native 계층을 연결하는 사고방식을 익히게 됩니다.
- CLI 환경이 필요한 이유를 가장 직접적으로 체감할 수 있는 프로젝트입니다.

### 마이 헬스 플랫폼

- 건강 관련 기능과 데이터를 하나의 서비스 구조로 묶는 플랫폼형 프로젝트입니다.
- 개별 기능 구현을 넘어 앱 전체 구조와 확장성을 설계하는 관점을 다룹니다.
- 화면 수와 기능 수가 늘어났을 때 필요한 정보 구조와 흐름 설계를 학습하게 됩니다.
- 앞선 프로젝트에서 익힌 기능들을 더 큰 서비스 단위로 통합하는 역할을 합니다.

## 이런 분들에게 적합합니다

- Expo 기반 프로젝트에서 한 단계 더 나아가고 싶은 분
- 네이티브 기능이 필요한 React Native 앱을 직접 만들어보고 싶은 분
- 화면 예제가 아니라 서비스 형태의 프로젝트 구조를 익히고 싶은 분
- 포트폴리오를 넘어 실제 출시 가능한 앱 설계 감각을 기르고 싶은 분
